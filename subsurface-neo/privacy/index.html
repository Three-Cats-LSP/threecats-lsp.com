Subsurface Neo Privacy Policy

Last updated: August 11, 2026.

Subsurface Neo is an open-source scuba diving logbook, planning and analysis application developed by Three Cats LSP. This policy describes how the application handles information when optional cloud synchronization is used.

Local dive data

Dive logs, equipment, dive sites, notes and related application data are primarily stored on the user's device. Subsurface Neo does not require Google or Dropbox synchronization to use local features.

Google Drive synchronization

If a user connects Google Drive, Subsurface Neo requests the Google Drive drive.appdata permission. This allows the application to create, read and update only its own hidden application-data files in Google Drive. Subsurface Neo does not request access to the user's ordinary Drive files, Gmail, contacts or calendar.

Dropbox synchronization

If a user connects Dropbox, Subsurface Neo uses Dropbox App Folder access. Its Dropbox permissions are limited to account identification and reading/writing metadata and content inside the application's own Dropbox folder.

Authentication credentials

OAuth access and refresh credentials used for synchronization are stored locally using platform security facilities where available, including Windows Credential Manager on Windows and Android Keystore-backed encryption on Android. Passwords for Google or Dropbox are never handled by Subsurface Neo.

Sharing and sale of data

Three Cats LSP does not sell cloud-synchronization data or OAuth credentials. Data synchronized to Google Drive or Dropbox is transferred to the provider selected by the user and is subject to that provider's terms and privacy practices.

User control

Users may disconnect a cloud provider from Subsurface Neo, which removes locally stored OAuth credentials. Users may also revoke Subsurface Neo from their Google or Dropbox account security settings.

Open-source software

Subsurface Neo is based on the open-source Subsurface project and its source code is publicly available.

Contact

Privacy questions may be sent to sns@rvm.cc.
